# COBOL85 SORT/MERGE テストスイート (ST)

このディレクトリには、COBOL85標準に準拠したSORTおよびMERGE機能をテストするための一連のテストケースが含まれています。これらのテストは元々NIST（米国国立標準技術研究所）によって開発された標準適合性検証システム（CCVS85、別名ANSI85）の一部です。

## 概要

STディレクトリにあるテストケースは、COBOLのSORT文およびMERGE文の機能をテストするために設計されています。これらのテストでは、さまざまなソートおよびマージ操作の正確性と効率性を検証します。

COBOLのSORT操作とMERGE操作は、データの並べ替えと結合に使用される重要な機能です。これらのテストケースは、異なるキーと並び順（昇順・降順）、入力ソース、出力先など、さまざまなシナリオでこれらの機能が正しく動作することを確認します。

## ファイル形式

テストケースのファイルは以下の2つの形式で提供されています：

* `.CBL` - 標準COBOLソースファイル
* `.SUB` - サブルーチンまたは依存モジュール

## 主なテストケース

### SORT機能のテスト

* **ST101A.CBL** - 基本的なSORT操作のテスト。単一のソートファイルに5つのキーフィールド（KEY-1からKEY-5）を定義し、基本的なSORT操作の動作を検証します。レコードには数値キーと英数字データが含まれます。
* **ST102A.SUB** - 複数のキーフィールドを使用したSORT。昇順と降順の複合キーを組み合わせたSORT操作をテストします。具体的には、KEY-1（降順）、KEY-2（昇順）、KEY-3（降順）、KEY-4とKEY-5（昇順）を指定し、USING句とGIVING句の基本的な使用方法も検証します。
* **ST104A.CBL** - 出力プロシージャを使用したSORT。ソート後のデータに対してOUTPUT PROCEDURE句を使用して追加処理を行う機能をテストします。ソート結果は出力プロシージャ内でレコード単位で取得され、処理されます。
* **ST106A.CBL** - 入力プロシージャを使用したSORT。入力データをINPUT PROCEDURE句を使用して動的に生成し、そのデータをソートする機能をテストします。プログラム内でレコードを作成し、RELEASE文を使用してソートプロセスに渡します。
* **ST108A.CBL** - 複雑なキー構造を持つSORT操作のテスト。8つの異なる型と使用法を持つソートキーを宣言し、それらすべてを昇順でソートする機能をテストします。複合型（COMPUTATIONAL、JUSTIFIED RIGHT、符号付き数値など）のキーフィールドが含まれます。INPUT PROCEDUREとOUTPUT PROCEDUREの両方を使用します。
* **ST109A.CBL** - 可変長レコードと複数ファイルを連携したSORT操作のテスト。このテストはST110A.SUBとST111A.SUBと連携して動作し、ST109Aが可変長レコード（50, 75, 100文字）を含むファイルを作成し、ST110Aがそのファイルをソートし、ST111Aがソート結果を検証します。降順と昇順キーの組み合わせも検証します。

### MERGE機能のテスト

* **ST112M.CBL** - 基本的なMERGE操作のためのデータファイル作成。このテストは3リールファイルを作成し、ST113Mにマージ処理のために渡します。出力は単一のコメント文のみで、実際のテスト検証はST113MとST114Mで行われます。
* **ST113M.SUB** - 降順キーでのMERGE操作のテスト。ST112Mによって作成されたファイルを入力として使用し、MERGE文で単一キーフィールドを降順に処理します。USING句とGIVING句を使用した基本的なMERGE構文をテストし、出力ファイルをST114Mでの検証用に生成します。
* **ST114M.SUB** - マージ結果の検証とテスト。ST113Mの出力ファイルを読み込み、予想されるレコード順序と内容を検証します。ソート順序が正しく適用されたかどうかを確認するために、特定のパターン（ALL-Z、ALL-N、ALL-Aで埋められたレコード）とその出現順序を検証します。これらのテストは連携して機能し、マルチリールファイルとの間でのMERGE操作の完全なテストサイクルを提供します。

### 特殊ケースのテスト

* **ST115A.CBL** - SORT操作でのリリース制限のテスト。大量のデータを扱うSORT操作の効率性とリソース管理をテストします。非コア常駐ソートルーチン（補助記憶装置を使用する必要があるほど大きなデータセット）の動作を検証します。固定長レコード（507文字/レコード）を使用し、OCCURS句を含む複雑なデータ構造を扱います。このテストは、ST116Aによって実際のソート処理が行われ、結果が検証されます。
* **ST118A.CBL** - 様々なデータ型と修飾子を持つSORT操作のテスト。コンパイラが8つの異なるキーフィールドを一度に処理する能力を検証します。SORT KEYとして複雑な組み合わせの基本データ項目（SIGN LEADING SEPARATE、JUSTIFIED RIGHT、SIGN TRAILING SEPARATEなどの修飾子を含む）を使用します。ST108Aの書き換えバージョンで、INPUT PROCEDUREでデータを生成し、OUTPUT PROCEDUREで結果を検証します。
* **ST119A.CBL** - SORT操作の結果の正確性と一貫性を検証するためのテスト。このプログラムはST120A（ソート処理）およびST121A（結果確認）と連携します。5つの数値キーフィールド（KEY-1からKEY-5）を含む構造体を使用し、REDEFINESを用いてさまざまなアクセス方法をテストします。結果が常に期待通りの順序に並べられることを確認し、ソート基準の正確な適用をテストします。
* **ST122A.CBL** - 可変長レコードと条件エラー処理を使用したSORT操作のテスト。レベル2の順次I-Oモジュールの機能（「RECORD IS VARYING IN SIZE」句）をテストします。3種類の異なる長さのレコード（50、75、100文字）を含むファイルを作成し、ST123Aでソートされ、ST124Aで結果が確認されます。INPUT PROCEDUREとOUTPUT PROCEDURE内でのエラー処理と例外処理の機能もテストします。

### 高度な機能

* **ST131A.CBL** - 3つのSORT操作を組み合わせたテスト。数値型とアルファベット型のキーを使用し、「USING-GIVING」、「INPUT PROC-GIVING」、「INPUT PROC-OUTPUT PROC」といった様々なSORT構成をテストします。
* **ST132A.CBL** - SAME SORT AREA句のテスト。USING-OUTPUT PROCEDURE構成、マルチリールソート、RELEASE FROM文、RETURN INTO文などの機能をテストします。
* **ST133A.CBL** - 同一データでの2つのSORT操作のテスト。INPUT PROCEDURE-GIVINGとUSING-OUTPUT PROCEDUREの組み合わせをテストします。
* **ST134A.CBL** - INPUT PROCEDUREとOUTPUT PROCEDUREを使用したSORT操作のテスト。これらのプロシージャはUSINGとGIVING句に相当する処理を行います。
* **ST135A.CBL** - SAME AREA、SAME RECORD AREA、SAME SORT AREAオプションを使った複雑なネットワーク共有のテスト。実際のデータ処理に加えてダミーファイルも使用して「SAME」オプションを徹底的にテストします。
* **ST136A.CBL** - RELEASE文のFROMオプションのテスト。降順のキーを持つレコードを作成し、昇順にソートする処理をテストします。
* **ST137A.CBL** - 可変長レコードとOCCURS DEPENDING ON句を使ったSORT文のテスト。NATIVEの照合順序を使用し、修飾付きの英数字および数値ソートキーをテストします。
* **ST139A.CBL** - ASCIIの照合順序と固定長レコードを使用したMERGE文のテスト。ALPHABET NAME句とCOLLATING SEQUENCE句を使用して、2つのファイルを昇順にマージする機能をテストします。
* **ST140A.CBL** - ASCIIの照合順序とマルチファイルテープを使用したMERGE文のテスト。マルチファイルリールの2番目のファイルと大容量ストレージファイルをマージして新しいファイルを生成する機能をテストします。
* **ST144A.CBL** - NATIVEの照合順序とマルチファイルテープを使用したMERGE文のテスト。ST140Aと似ていますが、ASCIIではなくNATIVE照合順序を使用します。
* **ST146A.CBL** - フォーマット2のOCCURS句（OCCURS INTEGER-1 TO INTEGER-2 TIMES DEPENDING ON）を使用した操作のテスト。可変サイズのテーブルに対するSORT操作とデータ処理をテストします。
* **ST147A.CBL** - NATIVEの照合順序と固定長レコードを使用したMERGE文のテスト。単一のMERGE文から3つの出力ファイルを降順で生成する機能をテストします。
* **ST301M.CBL** - COBOL中間サブセット機能の適合性フラグテスト。SORT/MERGE機能に関連する非標準機能が正しくフラグ付けされるかをテストします。このテストでは6つの非準拠標準（NON-CONFORMING STANDARD）メッセージが発生することが期待されています。

## テストの実行方法

STディレクトリに含まれるテストケースは、上位ディレクトリの一般的なテスト実行手順に従って実行することができます：

```bash
cd tests/cobol85
make test
```

ST特定のテストのみを実行するには：

```bash
cd tests/cobol85/ST
make test
```

## テスト結果

テスト結果は `report.txt` ファイルに出力されます。このファイルには、各テストケースの結果の概要が含まれています。
