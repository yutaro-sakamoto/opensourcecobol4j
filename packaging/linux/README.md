# opensource COBOL 4J (Linux x86_64 binary distribution)

This archive contains a complete installation tree of opensource COBOL 4J:

```
bin/      cobj, cobjrun, cobj-idx, cobj-api, cob-config
lib/opensourcecobol4j/   libcobj.jar, postgresql.jar
share/opensource-cobol-4j-<version>/config/  runtime configuration files
share/opensource-cobol-4j-<version>/copy/    copybooks
include/  libcobj.h
```

## Requirements

A JDK (Java Development Kit) version 11 or later. A JRE is not enough:
`cobj` runs `javac` and `jar`, and `cobjrun` runs `java`.

## Installation

### A. Install to /opt/opensourcecobol4j (recommended)

The binaries were built with `--prefix=/opt/opensourcecobol4j`, so if you
copy the contents of this directory there, no extra configuration is
needed besides `PATH` and `CLASSPATH`:

```sh
sudo mkdir -p /opt/opensourcecobol4j
sudo cp -r ./* /opt/opensourcecobol4j/
export PATH="/opt/opensourcecobol4j/bin:$PATH"
export CLASSPATH="/opt/opensourcecobol4j/lib/opensourcecobol4j/libcobj.jar:.:$CLASSPATH"
```

### B. Install anywhere else

Extract the archive wherever you like and point cobj at the config and
copybook directories with environment variables. With the extracted
directory in `COBJ_HOME`:

```sh
export PATH="$COBJ_HOME/bin:$PATH"
export CLASSPATH="$COBJ_HOME/lib/opensourcecobol4j/libcobj.jar:.:$CLASSPATH"
export COB_CONFIG_DIR="$(echo "$COBJ_HOME"/share/*/config)"
export COB_COPY_DIR="$(echo "$COBJ_HOME"/share/*/copy)"
```

(The directory under `share/` is named after the release version, hence
the glob.)

Note: `bin/cob-config` reports the paths the build was configured with
(`/opt/opensourcecobol4j`), so its output is only advisory under this
install method.

## Quick check

```sh
printf '       IDENTIFICATION DIVISION.\n       PROGRAM-ID. HELLO.\n       PROCEDURE DIVISION.\n           DISPLAY "HELLO WORLD!".\n' > HELLO.cbl
cobj HELLO.cbl
java HELLO
```

## Verifying this archive

Every release asset is listed in the `SHA256SUMS` file attached to the
GitHub release:

```sh
sha256sum -c SHA256SUMS --ignore-missing
```

Each asset also carries SLSA build provenance generated by GitHub
Actions:

```sh
gh attestation verify opensourcecobol4j-<version>-linux-x86_64.tar.gz -R <owner>/<repo>
```
