opensource COBOL 4J (Windows x64 binary distribution)
======================================================

This archive contains:

  bin\cobj.exe        COBOL-to-Java compiler
  lib\libcobj.jar     runtime library for the generated Java code
  config\*.conf       runtime configuration files
  copy\*.cpy          copybooks
  install.ps1         installer script (see below)

Requirements
------------

A JDK (Java Development Kit) version 11 or later. A JRE is not enough:
cobj runs javac and jar, and running compiled programs needs java.

Installation
------------

Run from this directory:

  powershell -ExecutionPolicy Bypass -File .\install.ps1

This copies the files to C:\opensourcecobol4j (change with
-InstallDir <dir>) and sets the user environment variables PATH,
CLASSPATH, COB_CONFIG_DIR and COB_COPY_DIR. Open a new terminal
afterwards.

Manual setup
------------

If you prefer to set things up yourself, copy this directory anywhere
and set:

  PATH            add <dir>\bin
  CLASSPATH       add <dir>\lib\libcobj.jar and .
  COB_CONFIG_DIR  <dir>\config
  COB_COPY_DIR    <dir>\copy

Quick check
-----------

  cobj HELLO.cbl
  java HELLO

Verifying this archive
----------------------

Compare the SHA-256 hash against the SHA256SUMS file attached to the
GitHub release:

  Get-FileHash .\opensourcecobol4j-<version>-windows-x64.zip -Algorithm SHA256

The archive also carries SLSA build provenance generated by GitHub
Actions:

  gh attestation verify opensourcecobol4j-<version>-windows-x64.zip -R <owner>/<repo>
